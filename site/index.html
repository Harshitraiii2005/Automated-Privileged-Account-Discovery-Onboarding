What happened in this run

The pipeline is a set of CLI stages; make demo runs them in order on a fresh lab.

  1. Build the lab

    make lab-up

    OpenLDAP with 200 fictional accounts, three Linux hosts (Debian, AlmaLinux, Ubuntu) and Vault in production mode with TLS and audit logging. 239 accounts carry seeded ground-truth labels.

  2. Discover

    autoonboard discover

    291 accounts found, 78 privileged, including privilege inherited through nested groups and sudo-via-group. 12 local accounts hold an SSH key that also unlocks another identity. No password hash is ever read.

  3. Classify and score risk

    autoonboard classify

    Rules 95.8%, gradient boosting 97.5%, hybrid 97.9% accuracy over 239 labelled accounts, each predicted by a model that never saw it. Each account also gets an explained 0–100 risk score.

  4. Plan

    autoonboard plan

    16 onboard (LDAP-ADM), 9 onboard (LDAP-SHARED), 28 onboard (LDAP-SVC), 2 onboard (UNIX-ROOT), 3 onboard (UNIX-SHARED), 36 remediate, 13 review.

  5. Approve (human in the loop)

    autoonboard approve

    58 items approved by security-lead, bound to plan hash d43c1c575142. The plan's author is not allowed to approve it.

  6. Onboard

    autoonboard onboard --dry-run && autoonboard onboard

    58 accounts vaulted into 13 safes, each with member and manager policies mapped to directory groups. Every password was changed on import and then verified by logging in.

  7. Rotate, verify, reconcile

    autoonboard cpm

    224 successful verifications, 116 password changes, 2 reconciles after simulated out-of-band changes, 1 failure that needed manual intervention.

  8. Report and evidence

    autoonboard report --pdf && autoonboard evidence

    HTML report and PDF with 8/8 Master Policy checks passing, plus a hashed evidence bundle for auditors.
